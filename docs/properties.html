Configuration

Every setting the service reads, with the value it uses when you say nothing. All 48 have working defaults: the service starts, classifies and serves its UI with no .env at all.

Core · Entity extraction and generation · Security · Storage · Embedding model · Retrieval · Confidence and UNKNOWN · Retrieval strategy · Multi-turn sessions · Observability

Nothing is required to start. Two values become mandatory once you turn on the feature that needs them:
  • API_KEYS — AUTH_ENABLED is true
  • OPENAI_API_KEY — LLM_PROVIDER resolves to openai
Set a variable in .env only to move it off the default below.

Settings come from the environment, or from .env beside the application. Environment variables win. Names are case-insensitive:

CONFIDENCE_THRESHOLD=0.65
LLM_PROVIDER=mock

Entity extraction and generation

Classification never calls a language model. These control the parts that do: entity extraction, and drafting domain instructions and intents.

VariableDefaultTypeWhat it does
ENTITY_EXTRACTION_ENABLED false bool Extract entities after a confident match. Off by default: it adds a network call.
LLM_MAX_RETRIES 1 int
≥ 0, ≤ 5
 Retries on a failed provider call.
LLM_PROVIDER auto "auto" | "openai" | "mock" | "none" auto uses OpenAI when a key is set. mock is an offline rule-based provider needing no key. none disables generation entirely.
LLM_TIMEOUT_SECONDS 10.0 float
> 0
 How long a provider call may take before giving up.
OPENAI_API_KEY
required when LLM_PROVIDER resolves to openai
 (empty) str OpenAI API key. Classification never needs one; extraction and generation do.
OPENAI_BASE_URL https://api.openai.com/v1 str Override to point at a compatible endpoint.
OPENAI_MODEL gpt-4o-mini str Model used for extraction and drafting.

Confidence and UNKNOWN

The thresholds that decide whether to answer at all. Calibrate them against your own evaluation set rather than by feel.

VariableDefaultTypeWhat it does
CONFIDENCE_THRESHOLD 0.55 float
≥ 0.0, ≤ 1.0
 Below this a result is UNKNOWN. Raise it to refuse more, lower it to guess more.
DENSE_SIM_CEIL 0.9 float
≥ 0.0, ≤ 1.0
 Similarity that maps to a dense score of 1.
DENSE_SIM_FLOOR 0.5 float
≥ 0.0, ≤ 1.0
 Similarity that maps to a dense score of 0.
MIN_DENSE_SIMILARITY 0.6 float
≥ 0.0, ≤ 1.0
 Hard floor on best cosine similarity. This is what rejects off-domain queries.
W_DENSE 0.35 float Weight of the dense signal in confidence.
W_MARGIN 0.25 float Weight of the lead over the runner-up intent.
W_RRF 0.25 float Weight of the fusion signal in confidence.
W_SUPPORT 0.15 float Weight of how many examples back the top intent.

Retrieval strategy

Changing retrieval is the riskiest change here, because a regression is invisible until the wrong tool gets called.

VariableDefaultTypeWhat it does
AB_TESTING_ENABLED false bool Assign a strategy per request by hashing the request id, so it stays reproducible.
AB_VARIANTS hybrid_rrf,dense_only str Comma-separated strategies to assign between.
AUTO_RESCUE_MARGIN 0.1 float
≥ 0.0, ≤ 0.5
 How far above the threshold an auto fallback must score. Without it, auto trades UNKNOWN detection for accuracy.
DEFAULT_STRATEGY hybrid_rrf str hybrid_rrf is the measured best. auto answers with hybrid and falls back only when hybrid cannot place a query, reporting which one resolved it.

Multi-turn sessions

Only active when a request carries a session id.

VariableDefaultTypeWhat it does
CONTEXT_FOLLOWUP_MAX_WORDS 3 int
≥ 0, ≤ 20
 A fragment this short counts as referential even without a pronoun.
CONTEXT_RESCUE_MARGIN 0.1 float
≥ 0.0, ≤ 0.5
 How far above the threshold a contextual retry must score. The retry includes the previous question, which alone can carry the match, so a rescue has to prove itself.
CONTEXT_RETRIEVAL_ENABLED true bool Retry an UNKNOWN follow-up with the previous question prepended.
ENTITY_CARRY_OVER_ENABLED true bool Carry entities from earlier turns into a new intent that accepts them.
SESSION_HISTORY_TURNS 5 int
≥ 0, ≤ 50
 Earlier turns shown to the extractor as history.
SESSION_MAX_TURNS 50 int
≥ 1, ≤ 1000
 Turns kept per session; older ones are pruned on write.
SESSION_TTL_SECONDS 604800 int
≥ 60
 Turns older than this are dropped.
SESSIONS_ENABLED true bool Record conversation turns when a request carries a session id.

Observability

Metrics and the audit trail are on; tracing needs a collector, so it is not.

VariableDefaultTypeWhat it does

AUDIT_LOG_QUERY_TEXT false bool Record the raw query text. Off by default: user queries can carry personal data.
